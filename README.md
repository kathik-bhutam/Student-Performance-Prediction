
# Student Performance Prediction

## Project Description
This project predicts student final marks using Machine Learning.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Streamlit

## Machine Learning Algorithm
Linear Regression

## Input Features
- Study Hours
- Attendance
- Previous Marks
- Assignment Score

## Output
Predicted Final Marks

## How to Run

1. Install the required libraries:
   pip install -r requirements.txt

2. Run the application:
   streamlit run app.py

## Note
This is an educational project using a small fictional dataset.
